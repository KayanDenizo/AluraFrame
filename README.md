# 💈 Barbearia Alura

Site da Barbearia Alura, desenvolvido no curso de HTML e CSS da Alura.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## Páginas

- Página inicial
- Página de produtos
- Página de contato

## Como rodar

Não precisa instalar nada: basta abrir o arquivo `AluraFrame/assets/index.html` no navegador (ou usar a extensão **Live Server** do VS Code).
